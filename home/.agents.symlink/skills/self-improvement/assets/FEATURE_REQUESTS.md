# Feature Requests

開発中にユーザーからリクエストされた、不足している機能。

**Areas**: frontend | backend | infra | tests | docs | config
**Statuses**: pending | in_progress | resolved | wont_fix
**Complexity**: simple | medium | complex

## Status Definitions

|    Status     |               Meaning                |
| ------------- | ------------------------------------ |
| `pending`     | 未対応                               |
| `in_progress` | 開発中                               |
| `resolved`    | 機能実装済み（解決策ブロックを追加） |
| `wont_fix`    | 開発しない（理由は解決策に記載）     |

エントリーのフォーマット: self-improvement スキルの **Feature Request Entry** セクションを参照。ID は `FEAT-YYYYMMDD-XXX` を使用。
