# Errors

開発中に捕捉されたコマンドの失敗、API エラー、予期せぬ振る舞い。

**Areas**: frontend | backend | infra | tests | docs | config
**Statuses**: pending | in_progress | resolved | wont_fix | promoted | promoted_to_skill

## Status Definitions

|       Status        |             Meaning              |
| ------------------- | -------------------------------- |
| `pending`           | 未対応                           |
| `in_progress`       | 対応中                           |
| `resolved`          | 解決済み（解決策ブロックを追加） |
| `wont_fix`          | 対応しない（理由は解決策に記載） |
| `promoted`          | AGENTS.md に昇格                 |
| `promoted_to_skill` | 再利用可能なスキルとして抽出     |

エントリーのフォーマット: self-improvement スキルの **Error Entry** セクションを参照。ID は `ERR-YYYYMMDD-XXX` を使用。
